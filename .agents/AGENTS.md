# hass-lebensmittelwarnung

Home Assistant Custom-Integration für lebensmittelwarnung.de.

Maßgebliche Einstiegsdatei für KI-Agents ist [`CLAUDE.md`](../CLAUDE.md) im
Repo-Root – die importiert alle Dateien in diesem Ordner automatisch in jede
Claude-Code-Session. Diese Datei ist bewusst kein zweiter Import-Index (sonst
laufen beide beim nächsten neuen Thema wieder auseinander), sondern nur ein
Verweis für Tools, die gezielt nach `AGENTS.md` suchen.
